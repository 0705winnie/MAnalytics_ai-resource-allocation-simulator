# Workstream A Deliverables

Start here:

- `workstream_a_assumptions.md` defines the problem formulation, system setup, request classes, hidden demand environment, and dependencies for Workstreams B, C, and D.
- `workstream_a_data_dictionary.md` defines the historical-data schema and marks student-facing versus hidden fields.
- `workstream_a_validation_summary.md` records validation checks and type-level reasonableness checks.
- `workstream_a_exploratory_plots.md` links to the generated SVG plots.

Data files:

- `synthetic_historical_requests.csv` contains one synthetic year of request-level historical data.
- `summary_by_month.csv` summarizes demand, completions, and revenue by month.
- `summary_by_type.csv` summarizes demand, required units, durations, completions, and revenue by request type.
- `summary_by_month_and_type.csv` supports the dashboard/report month-by-type views.

Generated plots live in `plots/`.
